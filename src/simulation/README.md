# Data Simulation

`main.py` contains a simple simulation tool that produces events for cows on a dairy farm. You can tune various parameters, including the number of cows and simulation years.
The tool's main purpose is to easily create dummy data. This can be used to:

- Try out working with the library
- Stress test systems using the library

Although the tool aims to create biologically plausible data, this is not the main purpose. The simulation is therefore heavily simplified. It is also not optimized for performance and can take a few minutes to run with the default settings.
